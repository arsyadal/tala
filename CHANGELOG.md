# Changelog

User-visible changes are recorded here. Tala follows [Semantic Versioning](https://semver.org/) and the [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

## [Unreleased]

### Added

- Native Rust terminal workspace targeting Windows, macOS, and Linux on x64 and ARM64.
- Folder navigation and read-only UTF-8 previews. New sessions start in the selected workspace.
- PTY terminal tabs with keyboard and mouse controls, scrollback, and the system clipboard.
- Shell and coding-agent discovery, including Codex, Antigravity, Oh My Pi, and Pi when their executables are installed.
- Git status and diffs, staging, commits, fetch, fast-forward-only pull, and push.
- Optional TOML configuration for the default shell, scrollback, and mouse input.
- Native build and test matrix and a gated GitHub release workflow.
- English and Indonesian setup, usage, and release documentation.
